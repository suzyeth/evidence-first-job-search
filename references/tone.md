# 写作风格检查表

> 适用于简历、求职信、LinkedIn About、面试 talking points。

## 总原则

**Concrete over abstract. Verbs over adjectives. Numbers over claims.**

招聘官扫一份简历平均 6–8 秒,每个词都要争取注意力。

## DO ✅

- **动词开头**:Designed / Shipped / Owned / Balanced / Wrote / Reduced / Increased
- **量化**:"Designed X that increased Y by 23%",而不是 "Designed effective X"
- **具体**:"Wrote 40-page system design doc for Season 3",而不是 "Wrote design documentation"
- **主语清楚**:求职信用 "I led…",不用 "Was responsible for leading…"
- **简洁**:"Reduced load time 40%" 胜过一整句被动描述

## DON'T ❌

- 形容词堆叠:passionate / driven / dedicated / hardworking / detail-oriented
- Buzzword salad:leveraged synergies / drove cross-functional alignment / spearheaded innovative solutions
- 模糊动词:helped with / worked on / involved in → 你**具体做了什么**?
- 被动语态
- 夸大 → 面试一问就穿帮
- 网络流行语 / emoji

## 双语

- 英国 / 欧洲 / 美国 / 远程:英文
- 中国大陆:中文,且**用中文语气重写**,不是翻译英文版(英文里正常的强观点,直译成中文会显得过激)
- LinkedIn 默认英文

## 按受众调整措辞

同一段经历,面对不同公司强调不同侧面,但**事实不变**。例:免费游戏商业化经验,面对 F2P 公司可以直说数据和付费设计;面对买断制 / 独立公司包装成 "progression and reward systems for live service",但面试中不否认。

## 动词词库

- 设计:Designed, Architected, Specified, Modeled, Prototyped, Iterated
- 实施:Built, Shipped, Delivered, Implemented, Launched, Integrated
- 优化:Balanced, Tuned, Optimized, Refined, Calibrated
- 协作:Owned, Led, Coordinated, Facilitated, Partnered with
- 文档:Authored, Documented, Presented
- 成果:Increased / Improved / Reduced / Cut / Boosted

## 写完过一遍

- [ ] 每条 bullet 动词开头
- [ ] ≥ 50% 的 bullet 有具体数字
- [ ] grep 一遍 passionate / driven / dedicated
- [ ] grep "was" / "were" 查被动
- [ ] 第一句话 5 秒内让人知道你是谁、能做什么
- [ ] **事实边界**:对每段经历,在 master-cv 里写一个"做过 / 没做过"清单,写完每条 bullet 对照一遍。自问:"如果面试官问 'tell me about a specific X you did there',我能说出具体的系统 / 功能 / 提交吗?" 答得出就留,答不出就改措辞或删。
